'matra': minor

The `matra check` command checks text from `--text` or from each line of a `--file` against one or more `--font` files. It prints the findings, or JSON with `--json`. Exit code 0: no findings; 1: findings; 2: a usage error, such as a missing option, a file that cannot be read, or a font file that is not a font.
