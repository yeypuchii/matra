# Security policy

## Report a vulnerability

Do not open a public issue. Use GitHub's private report instead: on the repository page, open **Security → Report a vulnerability**. You get a reply within a week.

matra reads font files and text that can come from users, so reports about crafted fonts or strings that cause a crash, a hang or very high memory use are in scope. A fault inside HarfBuzz itself goes to the [HarfBuzz project](https://github.com/harfbuzz/harfbuzz/security), but tell us too, so we can pin a fixed version.

## Supported versions

Before 1.0, only the latest 0.x release gets fixes.
