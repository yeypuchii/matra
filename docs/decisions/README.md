# Design notes

From the M2 milestone on, each item starts with a short design note here, before the code. A note records a choice that a later reader could not see from the code alone: what was decided, why, and what was not chosen.

Name the file `NNNN-short-title.md`, numbered in order, and copy [`0000-template.md`](0000-template.md). Keep it under a page. When a later note replaces an earlier one, say so in both.
